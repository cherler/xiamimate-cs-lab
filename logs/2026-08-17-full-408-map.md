## 一、复用比数量重要

30 个实验只用了 **4 个共享视觉原语**：

| 原语 | 服务的实验 |
|---|---|
| `BitField` 位域拆解 | IEEE754 · 虚存 · 子网划分（CRC / 海明码另有专用竖式） |
| `TreeView` 二叉树 | AVL · 哈夫曼 |
| `GraphView` 图 | Dijkstra · MST · 拓扑与关键路径 · 图遍历 |
| `ptab` 逐轮表 | 十余个实验共用 |

**树用扁平数组 + 下标**表示，不用对象引用 —— 状态必须能 JSON 往返（标准 2），
带循环引用的指针结构过不去。这是 DSL「不能递归」那条限制在内核状态里的回响。

## 二、判据一律挂在定义级性质上

30 个内核，没有一个是靠"对答案"验的：

| 实验 | 判据 |
|---|---|
| IEEE754 | 逐位比对宿主 `DataView`（含 0.1 无限循环、1e-5 小数） |
| 定点乘除 | 比对宿主整数乘法；除法验 `商×除数+余数=被除数` |
| 流水线 | 周期数用公式 `段数+(n−1)`，不是数出来的 |
| CRC | **码字必须整除生成多项式**；14 位逐位翻转全被检出 |
| 海明码 | **校验子恰好等于出错位号** —— 逐位注入 7 次全吻合 |
| AVL | 中序有序 · 任意结点 \|bf\| ≤ 1 · 缓存高度 = 重算高度 |
| 哈夫曼 | **WPL = 所有内部结点权值之和**；编码必须是前缀码 |
| KMP | next 比对暴力求最长相等前后缀；主串下标全程单调不减 |
| B+树 | 所有键在叶子层且有序 · 叶子深度处处相同 · 键是严格分界值 |
| MST | Prim 与 Kruskal **总权值必须相同**；选出的边连通无环 |
| 关键路径 | 关键活动余量必须为 0；每个事件 ve ≤ vl |
| 动态分区 | 已分配 + 空闲恒等于总内存；不许留相邻未合并的空闲区 |
| 信号量 | 正确顺序不死锁 / 错误顺序**必须**死锁；mutex 只在 0-1 |
| CSMA | 退避 r 必须落在 {0 … 2^k−1}；达上限必须放弃 |

## 三、这一轮逮到的最重要的四个 bug

### 1. 图的连线根本没接在结点上（已上线好几轮）

SVG 用 `viewBox="0 0 100 100"` + `xMidYMid meet`，把**方形视口居中放进长方形元素**，
而结点用的是元素宽高的百分比。两套坐标系不重合，连线离结点中心 **50~125px**。
图"看着像那么回事"，所以 Dijkstra 从上线起就一直是错的。

修法：按容器实际宽高算 viewBox 高度做 1:1 映射；边权标签改走 HTML 覆盖层
（viewBox 非等比时 SVG 文字会被拉歪 —— 跟当初"圆点变椭圆"是同一个坑）。

**自检花了三次才对**：先只改 `preserveAspectRatio` 没红，再只改 viewBox 高度也没红 ——
因为两者任一单独成立都能对齐；原始 bug 是两处叠加才产生的。
> **探针没打在真正的根因上，绿灯就什么都不说明。**

### 2. 流水线停顿方向写反

`pipe` 按指令下标升序，下标小的**走得更靠前**。一条指令停顿时该跟着停的是它
**后面**的那些；我冻住了前面的，生产者永远到不了 WB，无前递用例直接跑满 200 周期上限。

### 3. 尾数补位方向写反

IEEE754 的尾数要**左对齐补零**，阶码才是右对齐。两处都用了 `padStart`，
10 的尾数 `010` 被补成 `…00010`，整串位右移 20 位，编码全错。

### 4. 调度器轨迹少跑一步（两份独立实现撞了同一个盲点）

`step()` 结算完最后一个进程直接 `return null`，「全部完成」被算出来又扔掉。
界面上那句「已完成 3/4」一直挂着。修完 phase0 的 exact 比较立刻红了 ——
统一内核与独立参考实现**都错**。这不是实现分歧是规格问题，两边各自补上。

## 四、判据本身修了三次

| 缺陷 | 修法 |
|---|---|
| 舞台签名用 `.className`，对 SVG 返回 `SVGAnimatedString` 对象 —— **一直在比垃圾** | 改用 `getAttribute('class')`，签名取深到 40 个元素 |

## 五、预置数据也要有区分度

动态分区第一版随手写的请求序列，四种放置策略只能跑出 **2 种**结果 ——
不是内核不对，是数据没区分度。拿它当预置，学生切换策略会看不出任何差别。
写了个搜索脚本找到能分出 4 种的序列，题目也跟着改到真正的分水岭上
（作业7 在四种策略下落在 60 / 280 / 0 / 500 四个不同起址）。
