# 2026-08-17 · 阶段 1：视图层

**结论**：三个实验全部接到真引擎上，**验收标准 3（单向数据流）已验**，六条标准全绿。

做法是先出可交互草稿（用真实轨迹数据）再动手搭 React —— 草稿改起来便宜，一次性丢掉不心疼。

---

## 设计方向

主题的自有语汇不是物理（连续场、渐变、平滑曲线），是**离散状态**：
命中/缺失、组×路矩阵、地址拆成 `tag|index|offset`。这个世界的仪器是**逻辑分析仪**。

| | 选择 | 为什么不是默认 |
|---|---|---|
| 底色 | 深靛夜底 `#14141C`（偏紫暖） | 避开"纯黑 + 荧光绿"那个常见默认 |
| 强调色 | 琥珀 `#F0B429`，**只给"当前步"用** | 结构编码信息：琥珀出现的地方就是 playhead |
| 语义色 | 好 `#45B39A` / 坏 `#E2664A` | 学生要秒读 |
| 排版 | 数据全走 mono + 加宽字距 + tabular-nums | 读起来像仪器读数 |
| **签名元素** | **地址位域拆解条** | 32 位按三段分色，用**正交虚线**（原理图走线惯例）连到目标组。这是抽象变具体的那一刻 |

**结构性差异**：粒子先生是连续仿真、时间轴是小控件；我们是离散步进，
所以**轴做成第一等公民的横带**。这条差异是主题逼出来的，不是装饰。

## 架构：视图层也必须可插拔

共享的：布局 · 轴 · 逐步日志 · 参数面板 · 读数 · 边界栏
每个实验自带的：**舞台（Stage）** · 参数规格 · 读数计算 · 语义色 · 轴上的量

```
web/src/
├── types.ts        视图层的可插拔契约
├── registry.ts     实验注册表 —— 加实验只改这里
├── shell/          共享框架
└── stages/         每个内核一个舞台
```

**加一个新实验 = 往注册表加一条，宿主框架一行不用改。**
这是接缝 5（渲染层可替换）在视图侧的落点。

三个舞台各自不同：Cache 是位域条+矩阵、调度是甘特图+队列、TCP 是锯齿曲线+状态机。
**同一套壳撑住三种完全不同的可视化**，这就是可插拔的实证。

## 草稿阶段修掉的三处

Playwright 冒烟测出来的：

1. **淘汰语义反了（会误导学生）** —— 格子显示新 tag 被划掉，读起来像"新值被淘汰"。
   实际是旧 tag 被挤掉、新的顶上。改成新值正常显示 + 下方红字"挤掉 0x0"。
2. **组 3–7 全空却占 40% 舞台** —— 空组压扁到 19px。
3. **连接线是贝塞尔曲线横跨整个网格** —— 改**正交走线**（原理图惯例），更短也更贴主题。

## 真版阶段修掉的四处

### ① 轴的柱高编码错了

草稿用柱高编码命中/缺失。**但命中不是"量"。**
改成：颜色管语义（好/坏），**柱高管滚动指标**（Cache 用滚动命中率、调度用完成比例、
TCP 用 cwnd/上限）。一条带两个通道，信息密度翻倍。

### ② 语义色的键泄漏了 Cache 词汇（真 bug）

`Tone = 'hit' | 'miss' | 'neutral'` —— 结果**调度实验的日志里每步都写着"命中"**。
那是 Cache 的词汇，跨内核不成立。

改成：色用领域中性键（`good/bad/idle`），**文案各实验自己给**：

| 实验 | 日志里的说法 |
|---|---|
| Cache | 命中 / 缺失 |
| 调度 | 运行 / 空闲 |
| TCP | 正常 / 超时 / 重复ACK |

> 教训：**跨领域复用的类型，它的取值也必须跨领域中性。**
> 枚举值里藏着一个领域的行话，就等于把复用写死在那个领域里。

### ③ SVG 线宽被非等比缩放拉变形

`preserveAspectRatio="none"` 下横竖缩放比不同，线宽跟着变形。
加 `vectorEffect="non-scaling-stroke"` 修好。

### ④ …但圆点还是变成了椭圆

`vectorEffect` **只管描边，不管填充**。`r={4}` 在被横向拉近 2 倍的坐标系里就是椭圆。
正解：**标记点不放进被拉伸的 SVG**，改成绝对定位的 HTML 元素。实测 9×9 正圆。

## 打单文件时踩的一个经典陷阱

把 Vite 产物内联成一个 HTML 时，守卫报"还有未内联的引用"，而且**同一个标签报了两次**。

根因：`String.replace` 的**替换字符串**里 `$&` 表示"被匹配的原文"，
而压缩后的 JS 包体里必然含 `$&` —— 于是它把原来的 `<script src>` 标签又插回去了。

**修法：用替换函数而不是替换字符串**（函数形式不解释 `$`）。

> 这个 bug 是守卫抓出来的。而守卫本身第一版也写错了 ——
> 查的是裸字符串 `/assets/`，可内联进来的 JS 包体自己就含这个字样，会误报。
> 判据要写在**标签**上，不是裸字符串上。

## 冒烟测试覆盖

`scripts/web-smoke.mjs`，五组：

```
【1】三个实验都能起来，且各自的舞台不同      ✅ 12/16/20 步
【2】标准 3：改一个状态，多视图一起变       ✅ 读数/轴/日志/舞台四处同步
【3】参数改动 → 重跑仿真                  ✅ LRU→FIFO、相联度→8 路
【4】验证器直通 UI                       ✅ 容量128/块64/8路 → 组数0.25，被拦下
【5】第二个 tab 真的是另一个视图           ✅ 4 个扫描点
控制台无错误
```

**第 4 组值得单说**：验证器不是后台的东西，它**直接接到 UI 上** ——
参数调成非法组合时，页面当场显示
`params 容量 128 除不尽 块64×路8 —— 实际 0.25`。
学生调坏了会知道为什么坏，而不是看到一个空白页面。

## 六条标准现状

| # | 标准 | 状态 |
|---|---|---|
| 1 | Model 不知道 View | ✅ 引擎零 DOM 依赖 |
| 2 | 状态可序列化 + 确定性重放 | ✅ 含自检；抓到过真问题 |
| 3 | **单向数据流** | ✅ **本轮补上** |
| 4 | 输出是轨迹，不是结果 | ✅ 含自检 |
| 5 | 内核可插拔 | ✅ 引擎侧 + 视图侧双重验证 |
| 6 | DSL 是唯一入口 | ✅ 含自检 |

**六条全绿。**

## 仍然不满意 / 没做的

- **参数只能选离散选项**，不能自由输入 —— 这是有意的（避免产生非法配置），
  但真实产品里应该允许输入 + 即时校验
- **访问序列不可编辑** —— Cache 实验最该让学生改的其实是访问序列，现在是写死的
- **没有真题绑定** —— 内容标准第 4 条（至少挂一道真题）还没做
- **没有分享链接** —— 状态可序列化已经具备，但还没做 URL 编码
- **没有录制导出** —— 增长环的关键一环，还没动
- **移动端只是能用**，没认真做（三栏在窄屏塌成单栏，但舞台仍偏宽）
