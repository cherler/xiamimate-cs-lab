## 追加 · 补基础缺口:4 个新实验(2026-08-23)

用户拍板「先补基础缺口」。四门课标准考纲对下来,补了 4 个期末必考却缺的:

| 新实验 | 课 | id | 教的基础 | 特色 |
|---|---|---|---|---|
| 二叉树遍历 | 数据结构 | `btree` | 前/中/后/层序,中序=有序 | 复用 TreeView;调用栈 vs 队列 |
| 补码定点加减 | 组成原理 | `addsub` | 符号位一起算,双进位判溢出 | 逐列进位链;两种溢出判法 |

### 「加一个实验」的完整清单(8 处联动,漏一处就红)

1. `src/kernels/<id>.ts` —— 内核(compile 预算 frames,step 返回 frames[i+1])。**必须先单独 `npx tsx` 跑轨迹验数字精确**。
2. `src/presets/*.ts` —— 预置数据(序列 Preset / 实体 EntityPreset);note 是能被证伪的主张。
3. `web/src/stages/<Name>Stage.tsx` —— 舞台;phasenow 的 log 记得包 `rich()` 才渲染粗体。
4. `web/src/registry.ts` —— import 内核+舞台+预置,写 Experiment 对象,**加进 EXPERIMENTS 列表**。
5. `src/ai/schema.ts` —— **`REQUIRED` + `ENUMS` 各加一行**。不加 `REQUIRED` → 前端直接「配置不合法:kind 未知」(这坑撞过)。
6. `web/src/guide.ts` —— 推演条目(question/step/verdict/read/try/**terms**);terms 引用的词条**必须在 `TERMS` 里存在且被引用**,否则「悬空引用」/「孤儿」都会红。
7. `web/src/brief.ts` —— 实验笔记(care≥80字/guess/tasks≥2/verdict 现算,空轨迹返回 null,星号成对)。
8. `tests/guide-content.test.ts` 的 `FIX` —— 补 A/B 夹具(两态说不同的话)。

引导图(`GuideDiagram.tsx` 的 `GUIDE_DIAGRAMS`)可选但已全做,冒烟 16e 会遍历核。

**守它的判据**:brief-content / guide-content / css-tokens / presets-claims / 冒烟(16b/16c/16e + 逐个走 500+步)。加完跑 `npx tsx tests/run-all.ts` + 全量冒烟。

### 撞过的坑
- **kind 白名单**:`schema.ts` 的 `REQUIRED` 不登记 → 配置不合法。
- **词条 terms**:悬空(引用不存在)/孤儿(定义了没人用)都红;gloss 要 ≥20 字。
- **EntitySpec 结构**是 `{ tables:[{type,label,columns,newRow}], presets }`,不是平铺的 label/columns。
- **GraphView 忽略 x/y**(圆形布局);EdgeTone 只有 plain/active/chosen/dropped/critical,没有 'bad'。
- **RIP 无穷计数**:分布式 Bellman-Ford 每轮必须**从邻居重算**(best=INF 起),不能拿上一轮当地板 —— 否则路由器失去全部邻居后旧路由降不回无穷。这个 bug 是断链场景才暴露的。
- **硬编码实验数**:冒烟【5】曾写死 `navs===30`,加实验就红 → 改成先数一遍再比。
