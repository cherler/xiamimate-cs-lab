## 二、深挖：最「哇」、最日常、最适合做对照实验的几个（篇章候选）

### 冰箱《通着电却是热的》— 已定稿（范例）
电(排除)→热(散热堵)→控制(过冷冻疫苗)→[化学:相变]→[数据:温度曲线]。
控制层与"汽车定速""空调""水车"同源。

### 油烟机《关了窗反而吸不动》
- 异常：新装的油烟机，关窗做饭反而满屋油烟。
- 藏着：流体（负压/补风 makeup air）、化学（油烟成分）、声学（风量 vs 噪声权衡）。
- **哇**：抽风机不是"凭空吸走"，是"把屋里空气排出去，得有等量空气补进来"。密封太好→负压锁死→越关窗越吸不动。
- 对照：开窗 vs 关窗、开一条门缝 vs 全密封，看排烟速率曲线分叉。
- 权衡（掌控）：开大档吸得净但吵、费电——没有免费的性能。

### 腌菜《腌一半最毒》
- 异常：镇上老人按老法腌菜，孩子吃了不舒服。
- 藏着：生物（乳酸菌发酵、盐抑杂菌）、化学（亚硝酸盐先升后降）、渗透压。
- **哇**：亚硝酸盐不是一直涨，是**先升后降**——腌到第 3–8 天是高峰（最危险），腌透了反而安全。"没腌透"比"腌很久"更毒，反直觉。
- 对照：不同盐浓度 / 不同温度，各画一条亚硝酸盐随天数的曲线，都是先升后降但峰值和时机不同。**完美的"读曲线"实验。**
- 生物意义真实、有公共健康价值。

### 油炸《油温越低越油腻》
- 异常：同样的做法，这次炸出来一口油、软塌塌。
- 藏着：传热（油 180℃ vs 水 100℃）、化学（美拉德上色、丙烯酰胺、油氧化）、物理（湿料爆溅）。
- **哇**：油温太低→表面不能瞬间形成硬壳→油往里渗→更油腻；太高→外焦里生。有个"甜点温度"。
- 对照：150 / 170 / 190℃ 各炸一块，比吸油量和上色。控制变量=油温。

### 电脑《游戏卡，但 CPU 不忙》
- 异常：镇上游戏厅新装的游戏卡顿，可 CPU 占用不高。
- 藏着：组成原理（Cache 命中/缺页）、内存（换页抖动 thrashing）。
- **哇**：卡不一定是"算不过来"，是"数据来不及喂"——瓶颈在访存不在算力。
- 对照：数据集大小 / 访问局部性，看命中率与卡顿。**cs-lab 的 cache 内核可直接搬。**
- 升级钩子：同一张组相联图，标 L1 Cache 是课本，标 **KV Cache 显存**就是推理引擎——见下。

### 语音助手《为什么 AI 想半天，还越说越快》
- 异常：镇上的 AI 问答机，问一句要愣半天，然后回着回着突然顺了。
- 藏着：推理引擎（prefill 首字延迟 / decode 逐字 / KV 缓存 / 连续批处理）。
- **哇**：它"愣住"是在读你整段话（prefill），"越说越快"是逐字往外蹦（decode）；同一问题第二次快是因为**缓存了前缀**。
- 对照：短问 vs 长问的首字延迟；单独问 vs 高峰期同时十个人问（连续批处理：吞吐↑但每个人的延迟↑——没有免费的性能，又一次押韵）。
- **元层次彩蛋**：你在游戏里带着 AI 助手，去修的正是"另一个 AI"。你天天用的那个 AI 就长这样。

### 红绿灯/车道《加一条车道，反而更堵》
- 异常：镇上为了缓堵新修一段路，结果更堵了。
- 藏着：算法（布雷斯悖论 Braess paradox）、排队论。
- **哇**：给路网加一条路，可能让所有人的通行时间都变长。反直觉到像魔术，但是真的。
- 对照：有那条路 vs 拆掉那条路，跑车流仿真比总时间。

### 网购《为什么隔着网线，钱是安全的》
- 异常：镇民不敢在网上付钱，怕被偷。
- 藏着：算法（非对称加密：公钥能公开、私钥不给人）、校验位。
- **哇**：有一把"锁"可以随便公开发给全世界，但只有你有钥匙能开。加密和解密用不同的东西——这颠覆"密码就得保密"的直觉。
- 日常、重要、且能可视化（锁箱子的比喻直接做成机制）。

## 三、跨物件"押韵"—— 世界感的来源

同一个原理，在不同物件里反复出现。玩家在 A 副本学的，B 副本能用上——这才是"世界"，不是散关卡。

- **反馈控制**：冰箱温控 = 汽车定速巡航 = 空调变频 = 水车调速器 = 燃气灶熄火保护。（都是"别用力过猛"）
- **热泵搬热**：冰箱 = 空调 = 热泵热水器。（制冷=搬热，不是造冷）
- **供水/压力耦合**：淋浴忽冷忽热 = 咖啡店二楼水小 = 一开多个水龙头就没劲。
- **"没有免费的性能"**：油烟机吸得净就吵、Cache 命中高就耗电、推理吞吐高则单人延迟大。
- **排队/调度**：银行叫号 = 超市收银 = 进程调度 = 推理引擎连续批处理 = 路由器排队。
- **相变吸放热**：冰箱制冷剂 = 出汗降温 = 高压锅 = 炒菜"锅气"。
- **叠加/相消**：降噪耳机反相 = 微波炉驻波 = WiFi 多径。

- **数据结构** ✅ 电脑(索引/文件系统)、快递(排序装箱)

## 六、收缩：玩法适配筛选 → 第一季主线

**筛选标尺（全来自 grill 定死的玩法）：**
1. 有反直觉的「哇」（最重要，没有就退化成"拨开关"）
2. 能摆对照实验（变量可控、对照有区分度）
3. 有"看不见的东西"可被工具扫出来
4. 能连锁多层（修一层带出下一层）
5. 有情感/后果（镇民真在乎）
6. 押韵到别的副本（学科复用 = 世界感）
7. 2D 像素能表现
8. 补上学科覆盖

**第一季 · 八个副本（排好序，每个标：学科 · 哇 · 押韵）**

| # | 副本 | 学科 | 哇 | 押韵（种下/回收） |
|---|---|---|---|---|
| 1 | 冰箱《通着电却是热的》 | 热+控制 | 制冷=搬热，搬不出去电再足也白搭 | 种下：反馈控制·热泵·没有免费性能 |
| 2 | 电风扇《对着吹却不凉》 | 物理 | 风扇根本不降温，只加速汗蒸发 | 回收：制冷=搬热（风扇不搬，只蒸发） |
| 3 | 抽水马桶《一按自己流光又停》 | 流体+化学 | 虹吸——水会"自己爬过弯"把自己抽干 | 种下：流体/压力 |

**这一季的弧**：修具体东西(1-4,物理/化学,轻松上手) → 看不见的系统(5-7,CS/AI/算法,抽象拔高) → 回到生活(8,生物,收束)。学科全覆盖，原理一路押韵，难度与抽象度爬升。主线不是学科目录，是**"这一类问题，我会了"**。

**被这一季刷下去的（留后备）**：洗衣机/电梯/蓝牙/扫地机器人/导航/网购加密——都过关，但学科或押韵在第一季已有代表，避免重复。第二季再上。

## 七、扩散·第二批（造物 → 它管理的理论）

**用户新点的：**
- **卷动晾衣架/滑轮**：滑轮组**省力必费距离**(机械优势,功恒定,经典哇)·张力·摩擦
- **行李箱**：万向轮滚动摩擦·四轮vs两轮受力分解·装满反而好推(重心)·拉杆强度(材料)
- **办公椅**：气压杆=**帕斯卡原理/氮气弹簧**(一按就降,哇)·五星脚支撑面防倾·人体工学
- **台灯**：LED能带隙发光vs白炽黑体辐射(为什么LED不烫省电)·色温/显色指数·**PWM调光频闪**(伤眼,哇)
- **光纤入户猫(ONT)**：光纤**全反射**(光怎么拐弯不漏)·**波分复用WDM**(一根纤跑多色光)·PON分光(全楼共享带宽/上下行不对称)·光电转换
- **烤箱**：辐射加热·美拉德+发酵·温控(跟冰箱押韵)
- **电磁炉**：**涡流感应加热**(锅热炉面不热、铝锅不行只能铁锅,绝佳哇)·功率调制·能效
- **豆浆机**：**生豆浆有毒需煮透**(胰蛋白酶抑制剂/皂苷,情感+哇)·假沸(皂苷泡沫80℃冒充沸腾,危险)·蛋白变性·防溢检测
- **智能音箱**：唤醒词/语音识别/LLM(推理引擎)·**远场麦克风阵列波束成形**(信号)
- **大模型APIKEY**(消费侧推理)：鉴权·**限流TPM/RPM**(为什么第10个请求被拒)·**Token计费**(长对话为什么越来越贵=上下文重复计费)·流式输出·重试退避
- **自部署大模型机(GPU/内存/网卡)**(生产侧推理引擎,最深)：见下方"CS/AI深度轴"

**我再加的（用户说没想到的更多）：**
- **电饭煲/热水壶**：**磁钢居里点**(水干前锁100℃,水干温度窜升磁铁失磁跳闸,绝佳哇)·模糊控制
- **吹风机**：康达效应(吸住球)·PTC加热·负离子
- **空气炸锅**：热风对流(其实是小烤箱)·破"更健康"迷思(哇)
- **U盘/固态硬盘**：闪存浮栅·**擦写寿命+磨损均衡wear-leveling**(算法)·删了为什么能恢复
- **快充头/数据线**：**PD协议握手**(这头充那机为什么不快,跟TCP握手押韵)·功率协商
- **机械键盘**：**去抖debounce**(按一下为什么不输出好几个,跟信号去抖押韵)·轴回弹
- **智能手表**：**PPG光电测心率**(绿光,手腕为什么测不准)·计步/睡眠分期(ML)
- **无线充电**：电磁感应(为什么慢/发热/隔远不行)
- **共享单车/ETC**：GPS定位开锁·潮汐调度(算法)·车牌识别OCR·RFID
- **显示器**：刷新率/响应时间(拖影)·背光PWM频闪·色彩

## 八、整理框架 —— Hub 物件 vs 单发物件

> 用户洞察："一个台式机就能展开很多很多。" 有些物件是**一整片副本区**，有些是**一次一个干净实验**。
> 这直接映射玩法：Hub=反复回去的深度地点，单发=满镇跑的多样委托。

### Hub 物件（一个地点，反复钻，长成一整片）
- **台式机**（修理铺常驻）：Cache·流水线·缺页·调度·死锁·索引·文件系统·TCP·散热降频·SSD磨损·电源过载… 一台机器=大半个 408。
- **厨房**（灶台/冰箱/油烟机/电磁炉/豆浆机/烤箱）：热·化学·流体·生物挤在一屋。
- **汽车/电动车**：力学·热机·反馈控制·电池·导航算法·感知ML。
- **手机**：电池·网络·传感器·散热·相册ML·输入法。
- **★ 自部署大模型机（终局 Hub）**：见下。

### ★ CS/AI 深度轴（一条从消费到金属的进度线，就是"推理引擎"轨）
玩家沿这条轴越钻越深，同一套原理换标签复现——这是 408 → 推理引擎的升级路，做成一个**逐步解锁的地点**：

| 深度 | 地点/物件 | 理论 | 押韵回收 |
|---|---|---|---|
| 消费侧 | 智能音箱·APIKEY | 首字延迟·限流·Token计费·流式 | 排队·没有免费性能 |
| 系统侧 | 台式机 | Cache·缺页·调度·文件索引·网络 | cs-lab 内核直接搬 |
| 生产侧·GPU | 自部署机的显卡 | 算力·**显存装不下(权重+KV Cache)**·量化变笨 | Cache→KV Cache |
| 生产侧·内存 | 自部署机的内存 | **并发一高就OOM**(每请求一份KV)·offload慢十倍·**PagedAttention显存碎片** | 跟 page.ts 缺页/碎片**同源** |
| 生产侧·网卡 | 自部署机的网卡 | 多卡互联NVLink·**张量/流水线并行**(大模型拆到多卡)·卡间通信成瓶颈 | 跟 pipeline.ts **同源** |

**结论**：显存装不下 = 缺页/分页（page.ts）；多卡拆分 = 流水线（pipeline.ts）；KV 驱逐 = Cache（cache.ts）。
**你 cs-lab 那些 408 内核，换个坐标轴就是推理引擎的求解器。** 一格都不浪费。

### 单发物件（一次一个干净实验，满镇跑的委托）
电风扇·马桶·晾衣架·行李箱·办公椅·台灯·电磁炉·豆浆机·电饭煲·吹风机·空气炸锅·快充头·机械键盘·无线充电… 每个一个清爽的"哇"，供多样性和节奏。
