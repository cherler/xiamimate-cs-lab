## 一、产品闭环：两个环必须都转起来

### 增长环
```
用户玩实验 ──▶ 一键录制 ──▶ 短视频 ──▶ 新用户 ──┐
     ▲                                          │
     └──────────────────────────────────────────┘
```

### 内容环
```
用户丢一道题 ──▶ AI 填 DSL ──▶ 验证器把关 ──▶ 入库 ──┐
     ▲                                                │
     └────────────────────────────────────────────────┘
              下一个用户直接读，零成本
```

两个环共用同一套引擎能力：**录制导出**和**验证器**。
这就是它们必须在架构里、不能当后期功能的原因。

内容环尤其关键：**每个用户的使用都在扩充资产** —— 花一次钱，产一个永久资产。

### 三层定价

| 层 | 内容 | 用户为什么来 | 钱 |
|---|---|---|---|
| 造物层 | 手搓 CPU、逆向拆解规范 | 造物欲 · 好奇 | 免费（付时间不付钱） |
| 应试层 | 四门课实验 + 真题 + 判题 + 进度 | 考研 / 期末 / 笔试 | 99–299 · 主要收入 |
| 职业层 | 机器人学、分布式、数据库内核 | 工作要用 | 高客单价 · 后置 |

造物层不是慈善 —— 它跟应试层**共用内核**（手搓 CPU 的逻辑仿真就是组成原理的内核，
拆 TCP 握手就是计网的内容），边际成本接近零，传播性却最强。

## 二、技术架构：四层流水线

```
        文档模型 Document
             │
             │  compile()          ← 接缝 1，全部的关键
             ▼
        仿真模型 SimModel
             │
             │  run()
             ▼
          轨迹 Trace
             │
      ┌──────┴──────┐
      ▼             ▼
    渲染          验证
```

**408 只需要仿真，造物型必须要编辑。** 仿真的状态是随时间演进的*轨迹*，
编辑的状态是一份被修改的*文档*。两者不是一回事，但可以串成一条链 ——
不同的路从不同位置进入。

### 六条路，一张矩阵

| 方向 | 文档层 | 编译 | 仿真层 | 轴 | 渲染 | 出口 |
|---|---|---|---|---|---|---|
| **408 专业课** | 退化（一组参数） | 近乎恒等 | 离散状态机 | `time`·`parameter` | SVG+DOM | 视频素材 / 分享链接 |
| **手搓 CPU** | 电路图（门+连线） | 网表提取+拓扑排序 | 时钟驱动状态机 | `time` | SVG+DOM | Verilog / 网表 |
| **逆向拆解** | 层级结构（嵌套） | 层级展开 | 轴换成深度 | `depth` | SVG+DOM | 拆解动画 |
| **机器人学** | URDF（连杆+关节） | 运动学链 | 数值积分 / 迭代搜索 | 全部四种 | three.js | **URDF** |
| **PCB → 实体** | 版图（焊盘+走线） | — | 不进仿真 | — | SVG | **Gerber** |
| **虚拟工厂** | 装配（零件+约束） | 约束求解 | 连续物理 | `time` | three.js | — |

**手搓 CPU 和 408 共享的是"仿真层"，不是整条链。**
手搓 CPU 多出文档层和 compile；PCB 反过来，只有文档层和导出，压根不进仿真。

### 五条接缝，408 阶段就要划

| # | 接缝 | 408 阶段长什么样 | 不划的代价 |
|---|---|---|---|
| 1 | `compile(doc) → simModel` | 几乎恒等映射，但函数存在 | 手搓 CPU 时重写整条链 |
| 2 | 验证器四种比较器 | 只用 `exact` | 机器人 / PCB 时另起炉灶 |
| 3 | `Exporter` 接口 | 视频素材 + 分享链接 | Gerber / URDF / Verilog 各写一遍 |
| 4 | `Axis` 泛化 + `entities` 嵌套 | `time` + `parameter` | 拆解和黑盒器件都得改 |
| 5 | 渲染层可替换 | SVG+DOM | 机器人学接不进来 |

### 四种比较器

| 比较器 | 用在哪 | 强度 |
|---|---|---|
| `exact` | 408：命中/缺失、淘汰序、调度顺序 | 唯一答案，最强 |
| `tolerance(eps)` | 机器人：末端位姿、关节角 | 数值接近即可 |
| `structural` | 编辑域：网表拓扑、DRC | 结构等价 |
| `property` | IK 多解、RRT 随机路径、PID 稳定性 | 只能验性质，最弱 |

> **比较器的强度决定 L3 的天花板。** AI 生成新原语敢不敢开，取决于把关的闸有多严。
> 408 用 `exact` 闸最严，L3 最有机会；机器人学退化到 `property`，L3 天花板更低。

### DSL 三层

| 层 | 能力 | AI 可靠度 | 需要什么 |
|---|---|---|---|
| L1 参数级 | 换数值、换初始条件 | 100% | 立刻能做 |
| L2 组合级 | 用已有原语组装、并排对比 | 高 | 立刻能做 |
| L3 新原语 | 生成新的状态转移逻辑 | 不确定 | 沙箱 + **验证器** |

## 四、未决

- **"没有中文的四门课综合平台"这个判断只跑了 3 组关键词**，远不到 20 组。
  限流的空返回和真的没有长得一样。开工前要补一轮，且要直接翻 B 站/小红书/知乎。
- L3 可能做不成 —— 阶段 1／2 不依赖它
- 浮点确定性重放没实测（WASM 是严格 IEEE 754，但这是推理不是实测）
- 虚拟工厂的约束求解完全没调研
- 逆向拆解**选错对象会从最便宜变最贵**：拆规范与架构几乎白拿，拆商业实物有版权与商业秘密风险
- 规模天花板：粒子先生服务约 1700 万在校物理生，我们最乐观 240 万在校 + 40 万考研，
  差一个数量级。大概率是年营收百万级的生意
