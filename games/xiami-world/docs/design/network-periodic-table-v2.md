## 一、总览

玩家手里最底层的是「概念原子」——拼不出来、只能指着说"就是它"(比特、电平、标识、密钥……)。不是按形状硬拼(那是乐高),而是**要懂那条网络原理才知道什么能和什么合**(那是化学):每条反应式就是一条原理,拼错了不反应。合成物经动画**变态**成新形象(帧、IP地址、TCP连接、路由器),合成时**涌现**出任一原子都没有的新性质(可靠、能寻址、能跨网)。终点是一件**有真实规格的唯一实物**——规格由拼进去的组件当场定死。吉祥物咕噜在你卡住时给反应解说。

课程对齐谢希仁《计算机网络》/ Kurose-Ross,自底向上五层,**下探到物理层的比特/信号/电平/调制/介质**。

## 二、元素周期表(44 个概念原子)

> 拼不出来的最底层"元素",按层从底(物理)到顶(应用)。

### 物理层(7)

| 概念原子 | 定义 | 为什么不可再分 | 形象 |
|---|---|---|---|
| **比特** | 信息的最小单位,只有0/1,是真正要送到对面的东西 | 信息的底,再往下没有更小的信息;电平/波只是载它的工具 | 只有黑白两面、能翻面的小方块精灵,排队等上路 |
| **电平** | 介质里那个物理量此刻有多强:铜线电压、光的亮暗、场强 | 物理世界的原始量,拿仪表一量就是个数,拼不出几伏 | 一根发光液柱/调光旋钮,咕噜拧它调高低 |
| **时间** | 一切多久/何时/每秒几次的底座 | 最原始的物理轴,频率/速率/相位都从它派生,自己造不出 | 匀速摆头滴答的节拍器精灵嘀嗒 |
| **距离** | 信号要跨过的空间长度 | 与时间正交的原始物理量,只能拿尺量 | 咕噜手里会伸缩的黄色卷尺精灵 |
| **介质** | 信号赖以传播的实物:铜双绞线、玻璃光纤、空气 | 一样具体物件,只能指着那根铜线说就是它 | 三根可互换的管子:红铜管/玻璃管/虚线空气管 |
| **噪声** | 系统之外硬塞进信号的、不可预测的随机抖动 | 本质是来自外部的随机性,只能承认它在 | 浑身电视雪花、沙沙作响的噪点小妖 |
| **双工** | 同一时刻能否双向收发:单工/半双工(轮流)/全双工(同时) | 方向能否并发是一条独立物理设定,直接决定要不要跑冲突检测 | 管子上的箭头:单向/来回翻转配红绿灯/上下两条各走各的 |

### 数据链路层(11)

| 概念原子 | 定义 | 为什么不可再分 | 形象 |
|---|---|---|---|
| **界标** | 在连绵比特流里约定一个特殊记号,表示一段从这起/到这止 | 哪算一段是人为划的界,比特本身只有0/1推不出来 | 一对金色小书立,成对夹住中间那串比特 |
| **标识** | 把这一个节点从共享线上唯一挑出来的记号——一个名字 | 这串比特代表那台机器只能被指派,不能被计算 | 一块空白椭圆号码牌胚子,冲压出字样才有身份 |
| **冗余校验** | 检错的原语:由数据本身算出几位验算位一起发,收方重算对账(奇偶/校验和/CRC/海明码都是它的下游) | 自算一笔账、收方对账是检错的最小想法;它只管检、纠错要另加 | 一枚火漆封印,内容改一字花纹就对不上 |
| **侦听** | 发送前先感知介质忙闲,忙就先不发 | 先感知再行动这一下是接入的感知原语 | 咕噜把大耳朵贴在电缆上听信号球 |
| **退避** | 撞了或忙就各等一段随机时间再试 | 用随机打破对称是独立策略原语,固定等待不是退避 | 咕噜掏骰子,掷几点数几秒,邻座点数不同于是错开 |
| **确认** | 收到后回一个收到了信号,不含数据(跨层原子,链路/传输都用) | 凭一记回声判断收没收到是可靠性最小反馈原语 | 一只回声铃铛,信到叮一声弹回寄件人 |
| **封装** | 把上层数据当黑盒,前加首部、后加尾部,包成本层单元 | 分层接力的根本动作,首部/尾部只是它的部件 | 信封精灵吞下上层包裹,自动印地址、盖封条 |
| **定时器** | 一寄出就倒数,到点还没等到回执就叮报警(跨层原子:超时重传/退避/TTL/表项老化共用) | 时间流逝到上限即触发事件,别的原子没有时间维度 | 会走动的发条沙漏,漏干就叮地跳起来 |
| **序号** | 给流里每个字节/帧烫一个只增不减的顺序号(跨层原子:链路ARQ与传输都用) | 第几个/位置这个计数本身,有它才谈得上乱序/丢号/重复 | 排队机吐出的顺序小票,烫金#1001 #1002 |
| **固化** | 出厂一次性烧死、之后再也改不动的物理定型 | 把一串位锤进硬件后不可修改,是与可软配置正相反的原语 | 冷冲压机把位串锤进钢牌,锤下去就再也改不动 |
| **上层数据** | 从上一层交下来、本层不拆开只当黑盒转运的载荷(跨层原子:帧、IP分组的载荷都是它) | 本层无权解读其内容,对本层就是不可再分的一团黑箱 | 封着口、看不见里面、本层只管扛走的暖色黑箱包裹 |

### 网络层(8)

| 概念原子 | 定义 | 为什么不可再分 | 形象 |
|---|---|---|---|
| **子网掩码** | 一条从第几位切开的分界线(/n) | 纯粹的切点原语,网络号/主机号是它切出来的 | 暖黄镂空卡尺,卡进哪一位就把地址切成两半 |
| **TTL** | 分组随身携带的生存值,每转发一次减1,到0销毁 | 自带的自毁引信,转发只是拨扳机,造不出随身寿命本身 | 插在包裹上的一截燃着的引信 |
| **路由度量** | 给一段路贴的、可比较的代价数(跳数/开销/带宽反比) | 给路贴价越小越好归约成一个可比较的数 | 钉在路上的小价签/挂路口的小砝码 |
| **尽力而为** | 网络层最低承诺:尽力送,丢了不吭声、不确认、不重传、不保序 | 用拒绝做什么定义的服务地板,上层机制都是对它的反应 | 墙上邮件投递口:尽力投递·丢了不赔·不回执 |
| **无连接** | 无需事先建连,每个分组独立选路,路由器不为流存状态 | 与不可靠正交的另一条独立设计轴 | 每个包各自上路、谁也不记得谁的散兵 |
| **下一跳** | 同网直接由链路层直送,异网就交给下一跳,我只知下一跳不知全程 | 逐跳转发没人管全程却能到达的最小前提 | 岔路口只认下一扇门的指路牌 |
| **可软配置** | 可由软件随时赋值、更改、回收的软性设定 | 与固化正相反:值不焊死在硬件里,才谈得上DHCP/软寻址 | 一块可擦写的电子墨水门牌,咕噜用软笔随时改写 |
| **分层** | 把一个标识按高位/低位切成类别+个体两级的结构原语 | 命名要能分层聚合,必须先承认标识内部可切成上下两段 | 把号码从中间掐断成前段类别+后段个体的暖黄夹子 |

### 传输层(2)

| 概念原子 | 定义 | 为什么不可再分 | 形象 |
|---|---|---|---|
| **接收缓存** | 容量有限的暂存区,收进来没被取走的先堆着——它会满 | 有限暂存容量存储原语,流量控制的必要性全立在它会满上 | 带刻度的木桶,水位见顶就得喊停 |
| **连接状态** | 面向连接的通信里,两端(及沿途每跳)各自维护的、关于这条连接生存期的共享记忆(跨层原子:虚电路与TCP都用) | 面向连接vs无连接的分水岭,是两端凭空约定我们这条连接还活着这一原始能力 | 通信两端各自摊开的一本小账,记着我们这条连接还活着 |

### 应用层(16)

| 概念原子 | 定义 | 为什么不可再分 | 形象 |
|---|---|---|---|
| **进程** | 一个正在运行的程序实例,通信中主动收发消息的一端 | 谁在通信的那个谁,再拆是操作系统与字节 | 戴耳机、面前摆收发件筐的小工作精灵 |
| **名字** | 人取给人记的标签,只答是谁/是什么,不含在哪/怎么去 | 命名是最原始的动作,地址/路由拼不出能被人记住 | 手写牛皮纸吊牌,正面写名、背面空白 |
| **内容/数据** | 真正被通信的那团载荷:文本、像素、字节的应用级意义 | 报文正文、加解密/摘要/签名的对象,才是最基本的什么 | 一坨暖色泥料,尚未被命名、被封装 |
| **发起** | 主动发出第一条消息的权利与动作 | 对话最原始的不对称——总得有人先开口 | 暖橙色发令枪/哨子,谁叼着谁先发话 |
| **推/拉** | 发起方是内容的源(推,SMTP)还是内容的汇(拉,HTTP/POP) | 与发起正交的另一根轴:同样先开口,一个送货一个取货 | 发令枪上两个方向的小箭头:塞给你/要过来 |
| **约定码** | 从事先约好的清单里取一个记号,意义全来自清单第几条 | 意义只来自约定,拆开什么都不是——正是到底 | 刻着记号的小徽章,背面拴对照卡片 |
| **编码/表示** | 内容↔字节的可逆表示约定(ASCII/UTF-8/Base64/字符集) | OSI表示层原语,不是查表映射,而是如何序列化成可传字节 | 暖色打字机,把内容敲成一排可传的符号 |
| **状态** | 把上一条之后发生了什么记在心里,使下一条依赖之前 | 记住是最原始的时间粘连,有/无状态是应用协议分水岭 | 暖色记事本(有状态)vs转头就忘的小金鱼(无状态) |
| **权威** | 对某块命名/某份数据,谁说了算、谁的回答才作数的资格 | 可信来源的原始点,信任/委派/签名/证书全建在它上 | 暖色蜡封图章/小皇冠,盖过就作数 |
| **映射** | 一张把A换成B的对应(名字→地址、名字→记录、号→记忆) | 对应/查表是最原始的间接一跳 | 暖色查号簿,左页要查右页查到,中间发光线缝住 |
| **副本** | 内容可一模一样复制,复制品与原件不可区分 | 可无损复制是数字信息的原始性质,缓存/CDN/P2P的共同地基 | 暖色复印机,吐出的每张与原稿分毫不差 |
| **有效期** | 一份存下来的信息带一个到点作废、该重取的倒计时(TTL) | 信息会过期的最小刻度,缓存一致性全靠它 | 趴在副本上的小沙漏,漏光副本就发灰 |
| **密钥** | 只有该知道的人才知道的一串信息,知道它=有权限/是本人 | 保密的原点是知/不知的二分,加密都从有一个秘密开始 | 暖金小钥匙,插进锁才转得动 |
| **非对称密钥对** | 成对的两把钥匙,一把锁的只另一把能开,由公钥算不出私钥 | 一种单向陷门数学性质,不是两把密钥的叠加 | 一对镜像钥匙,一把只顺一把只逆,照不出对方齿形 |
| **哈希** | 把任意长内容压成固定长指纹:同内容同指纹、改一位全变、不可逆 | 易算难逆的原始数学性质,完整性/签名/证书都以它为基 | 暖色封蜡机,塞进什么都吐一枚固定大小蜡封指纹,回不去 |
| **元数据** | 不是内容本身,而是描述内容/指示怎么处理它的旁注 | 信封上的字对信里的话的区分只能约定 | 贴在包裹外的便利贴:易碎/23kg/送三楼 |

## 三、反应表(151 条合成反应)

> 每行一条反应。**规则**=玩家必须懂的那句原理(解谜性所在);**涌现**=组合后才有、任一原料都没有的新性质;**形象**=变态后的样子。

### 物理层(28 反应)

| 反应物 | → 产物 | 规则(要懂的原理) | 涌现 | 形象 |
|---|---|---|---|---|
| 电平 + 时间 | **信号** | 信号=电平随时间变化的函数;不变的电平携带不了信息,信息得靠随时间起伏 | 出现波形,形状里能藏信息 | 暖色坐标纸上起伏爬行的发光曲线蛇 |
| 时间 | **时钟** | 时钟不是时间本身,是按固定周期给时间打等距刻度的机器 | 冒出可数的节拍+共同起点 | 咔哒摆动的黄铜节拍器 |
| 电平 + 时间 | **载波** | 一条纯正弦空车,恰有幅/频/相三个可独立调制的参数 | 三个可独立调制的旋钮(其中幅/相正交成I/Q两维),后面才长出ASK/FSK/PSK | 匀速抖动的正弦波跳绳挂三个旋钮 |
| 比特 + 电平 + 时间 | **NRZ编码** | 1抬高0压低,整个比特时隙保持,基带、不骑载波 | 比特第一次变成能跑的物理信号,但长串同码时钟会飘 | 小方块跳上高/低两级台阶站着不动 |
| 比特 + 电平 + 时间 + 时钟 | **曼彻斯特编码** | 用中点跳变方向表比特,每个比特必有一跳 | 自带时钟(自同步),代价是两倍带宽 | 每格正中一道上/下折线,闭眼踩折线也跟上拍 |
| 比特 + 电平 + 时间 + 时钟 | **差分曼彻斯特编码** | 用比特开头有没有跳变表0/1,中点仍保证一跳 | 判变没变而非绝对高低,抗极性反接 | 咕噜不看灯、只喊"变没变":每格起点探一脚看跳没跳,正中必跺一下续拍;线接反了也照读不误 |
| 信号 + 比特 | **码元** | 码元=一次发的最小信号单位,N态=log2N比特/码元 | 波特率与比特率分家 | 多面骰子信号块,面数越多刻的比特越多 |
| 载波 + 比特 | **ASK振幅键控** | 只拧幅旋钮:1大振幅0关掉 | 比特第一次骑上载波能上空中,但抗噪最差 | 跳绳按比特忽粗忽细 |
| 载波 + 比特 | **FSK频移键控** | 只拧频旋钮:1高频0低频,振幅不变 | 信息藏在快慢里,抗噪强于ASK | 跳绳按比特忽快忽慢,粗细不变 |
| 载波 + 比特 | **PSK相移键控** | 只拧相旋钮:0°/180°,四相位一格装2比特(QPSK) | 又抗噪又能一格塞多比特,现代WiFi/4G基石 | 切换处啪地错半格,相位盘指针弹跳 |
| ASK振幅键控 + PSK相移键控 | **QAM正交振幅调制** | 同时拧幅+相两个旋钮,16/64/256-QAM一格塞更多比特 | 每码元比特数往上顶信道容量 | 星座图上一格格发光点阵,越密塞越多 |
| 电平 + 比特 | **量化** | 把连续电平切成有限档,每档对应一组比特(N档=log2N比特/样本) | 冒出量化误差/量化噪声 | 把液柱高度卡进一格格阶梯 |
| 信号 + 时间 + 量化 + 比特 | **PCM脉码调制** | 采样(fs≥2×信号带宽)→量化→编码;此奈奎斯特≠信道奈奎斯特 | 模拟→数字整条链路,PCM 64kbps电话语音 | 曲线蛇被等距竖线采样,每点量化成一串比特 |
| 电平 + 介质 + 距离 | **衰减** | 越走电平越小随距离累积,光纤最省铜线次之空气最费 | 冒出传输距离上限(弱到淹进噪声就读不出) | 曲线蛇每爬一段暗一截矮一截 |
| 信号 + 介质 | **失真** | 波形本身被介质扭歪(不同频率分量走得不一样→码间串扰ISI) | 第三种独立损伤,既非均匀衰减也非外来噪声 | 曲线蛇形状被拧歪,相邻码元糊在一起 |
| 距离 + 介质 | **传播时延** | 传播时延=距离/传播速度(~2×10⁸m/s);≠传输时延(=帧长/比特率) | 一段与"发多少数据"无关的纯路程耗时——只由线长和介质定,链路再宽也省不掉,和传输时延并列成两种独立的等待 | 信号球在管里飞一段的耗时 |
| 信号 + 噪声 | **信噪比** | 决定能否读对的不是信号多强,是它比噪声强几倍(功率比取分贝) | 冒出能把电平切多细;香农容量的一半原料 | 天平一头信号蛇一头噪点妖,指针指分贝 |
| 载波 + 介质 | **带宽** | 信道只让某段频率顺利通过,这段宽窄(Hz)就是带宽;≠口语100兆比特/秒 | 冒出每秒最多发几码元(奈奎斯特);香农容量另一半原料 | 介质入口一道频率梳子闸门 |
| 码元 + 时间 | **波特率** | 每秒发多少码元,不管每格装几比特 | 被带宽死死卡住(Rs≤2×带宽) | 传送带每秒咔地送固定个骰子 |
| 波特率 + 码元 | **比特率** | 比特率=波特率×每码元比特数;提速两条路:发更快or每格装更多 | 比特率可远高于波特率 | 出口把骰子拆开,比特计数器跳得快好几倍 |
| 带宽 + 信噪比 | **信道容量** | 香农C=带宽×log2(1+信噪比);此处信噪比取线性功率比(30dB要先还原成1000倍再代入,别直接代分贝);带宽给每秒几格上限,信噪比给每格几比特上限 | 一条不可逾越的物理天花板,把能多快变成可算的数 | 刻着C的天花板,各路小车顶不破只能贴着跑 |
| 信噪比 | **误码率BER** | 每传N比特错几个,由信噪比与调制方式定 | 把抽象的信噪比翻译成用户在乎的传对传错 | 一块计数板,每错一比特跳一格 |
| 时钟 + 信号 | **同步** | 收发时钟频率+相位对齐,才会在每比特正中采样;采样时刻错了全读错 | 冒出共享的时间线,曼彻斯特把它焊进了数据 | 两台节拍器对拍,采样箭头稳稳落每比特正中 |
| 带宽 + 载波 | **频分复用FDM** | 把带宽切成互不重叠的子带,各用一个频率载波,同时发不干扰 | 一条介质同时跑多条独立逻辑信道 | 管里并排流几条不同颜色的波 |
| 时间 + 介质 | **时分复用TDM** | 时间切成一轮轮时隙,轮到谁谁独占整条介质发一小段,飞快轮转 | 轮流独占,共享坐标从频率换成时间 | 入口飞转的分配转盘,转到谁灌一段 |
| 载波 + 比特 + 介质 | **CDMA/WDM复用** | CDMA给每人一串正交码片、同频同时发,靠码字正交在收端分离;WDM=光纤(介质)上的FDM,不同波长各走一路 | 复用四件套补齐(FDM/TDM/WDM/CDM) | 每人一套彩色码片叠加,收端靠正交解开 |
| 介质 + 曼彻斯特编码 + 同步 + 双工 | **物理链路** | 选介质+选线路编码(此处以自同步的曼彻斯特为代表,实际NRZ/8B10B/PAM4皆可)+做好同步+定好双工,两端各装收发器(PHY) | 涌现出有真实规格牌的唯一实物,对上层只暴露给我一串比特原样送到对面 | 插主板的网卡/光模块,烫金规格牌,一头咬管子一头吐干净比特队列 |
| 物理链路 | **中继器集线器** | 接两段物理链路,把衰减失真的信号放大(连噪声一起放)或再生(重新判决整形);集线器=多口中继器 | 突破最多拉多长线的距离上限 | 笨笨的多头三通,信号从一口进往其余每口全吐 |

### 数据链路层(28 反应)

| 反应物 | → 产物 | 规则(要懂的原理) | 涌现 | 形象 |
|---|---|---|---|---|
| 物理链路 + 标识 | **接口** | 给一段物理链路配上本地端口序号,成为设备一个可插线收发帧的网卡口(这是物理口,不是进程级的端口号) | 设备第一次有了可点名的物理收发口 | 机箱侧面编号的黄铜网口,插进一根管子 |
| 介质 + 双工 | **共享信道** | 多个节点共用同一段介质,同一时刻只一个能成功发(半双工共享) | 冒出会撞车,逼出接入控制 | 一根粗管子多个头一起挤着往里灌 |
| 封装 + 界标 + 标识 + 冗余校验 + 比特 + 上层数据 | **帧** | 物理层只吐比特;靠界标知哪段是一帧、靠标识知给谁、靠校验知坏没坏;载荷是当黑盒的上层数据(可能是IP包也可能是ARP) | 一个有头有尾、能寻址、可自检的离散单元 | 小火车厢:车头界标旗、侧面门牌、车尾火漆、肚里黑箱包裹 |
| 标识 + 比特 + 固化 | **MAC地址** | 一个标识+48位位串,前24位OUI后24位流水号,固化出厂烧死(ROM里的BIA;实际在用的可被软件改写,即MAC欺骗);它是扁平的,认人却无法寻路 | 全球唯一、出厂固化、扁平的硬件身份 | 冷冲压钢制铭牌,六段十六进制刻痕刮不掉 |
| 标识 + 帧 | **广播地址** | 目的MAC=FF:FF:FF:FF:FF:FF意为喊给本段所有人,每块网卡必收 | 本段一对全体的能力,埋下广播风暴隐患 | 画大喇叭、刻全F的号码牌 |
| 标识 + 帧 | **组播地址** | 目的=组地址(第一个字节的I/G位=1,如01:00:5E里首字节0x01的最低位),只有加入该组的网卡才收下 | 补齐单播/广播/组播三件套里的一对一组 | 刻着01:00:5E的号码牌,只有戴同色臂章的收 |
| 冗余校验 + 比特 | **奇偶校验** | 添1位让1的总数凑成偶(或奇),收方数一遍 | 能查奇数个翻转,偶数个抵消查不出,最弱但几乎零成本 | 算盘最右一颗奇偶珠 |
| 冗余校验 + 比特 | **校验和** | 分块反码求和取反带上,收方全加应得全1(这就是Internet校验和,传输层复用) | 比奇偶强、软件快算,但弱于CRC | 账房把每行加总,末尾盖合计戳 |
| 冗余校验 + 比特 | **CRC** | 整帧当大二进制数,模2除以约定生成多项式,余数附帧尾;收方再除余0则认对 | 擅长抓突发错、天生适合硬件流水线,故以太网FCS用它 | 带摇把的除法机,吐一小截余数压进火漆 |
| 冗余校验 + 比特 | **海明码** | 多个校验位站在2的幂位置交叉投票,不但发现错还能定位并翻转改回,无需重传 | 检错升级成纠错,接收方自己把错位纠回来 | 校验位交叉投票指出哪位翻了 |
| 侦听 + 退避 + 共享信道 + 帧 | **CSMA/CD** | 先听后发、边发边听,撞了立刻停+发拥塞信号,再指数退避 | 无中央调度也能分布式基本不撞地轮流用一条线,逼出最小帧长 | 独木桥,上桥探头途中盯着,双双退回各掷骰子 |
| 侦听 + 退避 + 确认 + 共享信道 | **CSMA/CA** | 测不到自己的碰撞→改成事前避让+事后ACK,紧张时先RTS/CTS预约 | 在测不到冲突的介质上仍能协调,可靠性从ACK涌现 | 浓雾吊桥:招手RTS、回招CTS、掷骰过桥、挥旗ACK |
| 确认 + 定时器 + 序号 + 帧 | **ARQ** | 发出即开定时器,超时或收否认就重传,用序号去重(停止-等待式自动重传) | 会丢会错的链路上得到不重不漏一定送达 | 抱包出门死等回执,沙漏叮了照存根补寄 |
| MAC地址 + 接口 + 帧 + 定时器 | **转发表** | 目的MAC查表:查到只往那口送,查不到泛洪,表项靠定时器老化 | 把广播式共享升级成点名式投递 | 门房桌上对照册,左门牌右走第几口 |
| 转发表 + 帧 + 接口 | **自学习** | 每收一帧就把源MAC↔从哪个接口进来反着记进表 | 即插即用,自动长出拓扑知识,配老化能纠错 | 门房瞄寄件人门牌+记下从几号口进,下次直接走对门 |
| 自学习 + 转发表 + 帧 | **网桥** | 自学习+转发+过滤,连接两段网;交换机本质就是多接口网桥 | 透明桥接:只转发跨段的帧、把本段流量挡在本段,一个冲突域就此一分为二,而两端主机毫无察觉 | 两段网之间的门房小亭 |
| 网桥 + 帧 | **生成树协议STP** | 网桥互相协商、互投BPDU、阻断冗余链路、长成无环转发树 | 环路→广播风暴的解药 | 多台门房互投BPDU,红叉封掉会成环的那条线 |
| 转发表 + 自学习 + 接口 + 帧 + 双工 | **交换机** | 每口独立冲突域(点到点全双工),按MAC精准投递,查不到才泛洪 | 分割冲突域(总带宽随口数叠加),但所有口仍在同一广播域 | 多门智能分拣柜,规格牌24口·千兆 |
| 交换机 + 帧 + 标识 + 广播域 | **VLAN** | 给口/帧打12位VID,只有同VLAN才互转互广播,跨VLAN必须上三层 | 不重新布线就把广播域逻辑切开、按部门隔离 | 不同颜色腕带,红只走红口,红绿间凭空立墙 |
| 广播地址 + 共享信道 | **广播域** | 交换机转发广播(不分割)、路由器不转发(天然边界)、VLAN逻辑切开;域越大风暴破坏面越大 | 划定广播能传多远 | 院子中央石墩喊一嗓子,声音盖住的整院 |
| 共享信道 + 帧 + 标识 | **受控接入** | 谁攥着令牌(一种特殊帧)谁才能发,令牌沿环轮流传递,无冲突、时延确定 | 补齐MAC三分法的第三类(静态划分/随机接入/受控接入) | 一枚令牌沿环传,接到才准发一帧 |
| 共享信道 + 频分复用FDM + 时分复用TDM | **信道划分** | 静态预先把共享信道分成互不干扰的份,每人固定用自己那份,根本不撞 | 无冲突无退避、时延确定;代价是有人没话说也空占 | 大水管竖隔板分几条,或管口按时段轮流开合 |
| IP地址 + MAC地址 + 广播地址 + 帧 | **ARP** | 同一LAN内广播谁是192.168.1.5,对方单播回MAC,缓存进ARP表(有老化) | 把逻辑地址(IP)翻译成硬件地址(MAC),是三层落到二层的接线口;广播可信故可被欺骗 | 举IP门牌灯大喊这门牌哪位,对应那家回喊钢制铭牌 |
| 帧 + 界标 + 透明传输 + 冗余校验 | **PPP** | 两点一根专线,不用寻址/抢介质;重点是0x7E成帧+透明传输+FCS+LCP/NCP协商+PAP/CHAP | 一条拨通就能跑IP的点到点链路 | 两咕噜间软管,首尾插7E旗,接通前握手对暗号 |
| 界标 + 帧 | **透明传输** | 数据里若出现跟界标一样的位,发端插转义符(或连5个1塞一个0),收端抠掉 | 任何比特组合都能安全当数据发,界标永不被内容误触发 | 给长得像书立的位贴这不是边界哦黄便利贴 |
| 帧 + MAC地址 + 冗余校验 | **以太网帧** | 前导码只给物理层打拍子不是数据;最小帧长64字节是被CSMA/CD逼出来的 | 全球统一、任意厂商网卡都认的标准信封,帧长64~1518 | 标准涂装火车厢,五格明确分区 |
| 以太网帧 + MAC地址 + CSMA/CD + 介质 | **以太网** | 一套帧格式+一套接入布线规格;10BASE-T/1000BASE-T把规格编进型号;早期共享总线靠CSMA/CD争用,全双工交换后CSMA/CD退役 | 可平滑升速(10M→10G)、全球通用的局域网技术 | 带水晶头双绞线,帧小火车飞驰,铭牌1000BASE-T |
| 以太网 + 交换机 + 广播域 + ARP | **局域网** | 同广播域内靠MAC+ARP直接可达不需路由器;一个IP子网通常正好映射一个LAN | 内部人人可直达、对外统一走网关的本地网 | 一间办公室,几台机器接中央交换机,墙角一道网关门 |

### 网络层(29 反应)

| 反应物 | → 产物 | 规则(要懂的原理) | 涌现 | 形象 |
|---|---|---|---|---|
| 标识 + 比特 + 可软配置 + 分层 | **IP地址** | 一个标识+比特串,可软配置(能拧上拆下),且自带分层(高位网络号/低位主机号);v4是32位v6是128位,正与烧死的MAC相反 | 可聚合、可路由的层级命名:一条前缀概括一大片、指向同一方向,正与MAC扁平、认得出人却无法指路相反 | 能拧上拆下的会亮门牌灯牌 |

| 网络前缀 + 最长前缀匹配 | **CIDR** | 可变长前缀+把多条路由聚合成一条短前缀对外通告 | 路由表可扩展、BGP通告可压缩的核心 | 一把大伞把一片小门牌收成一条短前缀 |
| IP地址 + 网络前缀 | **私有地址** | 10/8、172.16/12、192.168/16只在本地有意义,公网不可路由 | 同一段地址能在无数私网里重复使用、互不冲突——因为公网根本看不见它们 | 只在自家院墙内有效的内部门牌 |
| IP地址 + TTL + 校验和 | **IP首部** | 封面标签区:版本、源/目的IP、TTL、协议号、分片字段、首部校验和;基本20字节、带选项可到60,靠IHL字段指明多长——是变长的(定长的是IPv6那40字节基本首部) | 路由器只读封面不拆信,转发与内容彻底解耦 | 包裹正面一排冷压标签槽 |
| IP首部 + 尽力而为 + 上层数据 + 无连接 | **IP分组** | 把上层数据裹进带源/目的逻辑地址的首部,无连接每包独立选路,每段临时塞进帧投递;源/目的地址端到端不变(TTL、首部校验和每跳会变) | 跨网能力:穿过一连串异构网,首部收发地址全程不变 | 暖黄牛皮纸包裹,每到路由器换一层当地帧外包装 |
| IP分组 + IP首部 | **分片与重组** | 大于MTU就切片,靠标识+片偏移+MF定位;中途只切,终点按标识拼回 | 对异构链路透明;但丢一片整包重组失败且不重传 | 窄门口切成小包盖同批次火漆,终点按段号拼回 |
| 网络前缀 + 子网掩码 + 路由度量 + 接口 + 下一跳 | **路由表** | 每行=(目的前缀/掩码→下一跳+出接口+度量);压缩成拿目的地址查一下 | 本地知识驱动全局递送:只知下一跳,全程由各表接力涌现 | 邮局墙上翻牌分拣板 |
| 路由表 + 子网掩码 | **最长前缀匹配** | 多行命中时选前缀最长(最具体)那行——越具体越懂怎么走 | 让聚合与例外无歧义共存 | 一摞长短镂空尺套向门牌,卡最紧那把亮灯 |
| IP分组 + 路由表 + 最长前缀匹配 + 帧 + ARP + 无连接 | **分组转发** | 读目的IP→最长前缀匹配→下一跳+出接口→ARP查MAC→重封进出接口的帧;逐跳、无连接、每包独立 | 逐跳递送:没人管全程却能到达,同目的两包可走不同路甚至乱序 | 岔路口读TO灯牌选门,扒旧帧换当地新帧抛进去 |

| 路由表 + 路由度量 + 子网 | **RIP** | 周期性把我到各目的几跳告诉邻居,邻居套我=邻居+1取最小;16跳=不可达 | 纯邻里传话也能收敛到最短;通病坏消息传得慢 | 各家递小纸条,收到就把数字+1和自己比 |
| 路由表 + 路由度量 + IP分组 | **OSPF** | 只描述自己每条直连链路的开销,洪泛全AS→人人拼出同一张全网图,各自跑Dijkstra | 传链路事实而非算好的结论,收敛快、不互相传染错误 | 举牌广播我这几条路各多重,拼成整片地图描最短路 |
| 网络前缀 + 子网 | **自治系统AS** | 同一管理机构+全球唯一AS号;域内用IGP、域间用EGP(BGP) | 两级路由,把每台懂全世界降维成域内细算+域间谈策略 | 插同一面旗、围栅栏的领地,门口牌AS65001 |
| 自治系统AS + 路由表 + 路由度量 | **BGP** | AS间通告到某前缀要经过哪串AS(AS-PATH),按策略与商业关系选,扫AS-PATH防环 | 全球可达+各自为政,策略优先于最短 | 大门间互递盖满领地印章串的卷轴 |
| IP分组 + TTL + 尽力而为 + 分组转发 | **ICMP** | IP不给反馈,用装在IP分组里的控制报文补:不可达、TTL超时、需分片被禁、回显(ping) | 从纯尽力而为里长出可诊断性 | 咕噜口袋红哨,包被丢就吹哨塞回执逆流送回源头 |
| TTL + ICMP + 分组转发 | **Traceroute** | 发一串TTL递增的分组,每台把包烧断的路由器用ICMP超时报自己是谁 | 用两个原语反推出协议从没打算提供的整条路径可见性 | 连发引信一个比一个长的小包,谁烧断谁报名 |
| IP地址 + 端口号 + 分组转发 | **NAT** | 出网时把私网源(IP+端口)改成公网(IP+新端口)记进表,回包反向改回;多机靠端口复用一个公网IP | 地址复用+私网隐身;副作用:打破端到端 | 小区门房守进出登记簿,外人只看见大门一个门牌 |
| IP分组 + 封装 + 私有地址 | **VPN隧道** | 把一份IP分组再封进另一份IP分组;VPN、IPv6过渡(6to4)、移动IP共用此机制 | 在公网上凿出一条逻辑专用通道(私网地址跨公网可达);但机密性另需加密(密钥/IPsec),纯封装不等于安全 | 包裹外再套一层公网信封,穿过公网到对端拆开 |
| 连接状态 + 标识 + 映射 + 分组转发 | **虚电路服务** | 先建路径(连接状态)、沿途每跳存VC状态表(映射)、按VC号(标识)转发并保序;与数据报无连接对立 | 面向连接vs无连接的另一半,理解IP为何选无状态逐跳 | 先铺好一条固定轨道,车厢按轨道号鱼贯而行 |
| 组播地址 + 发起 + 状态 | **IGMP** | 主机发起加入/退出某组,路由器维护本网段的组成员状态 | 组播的成员管理:谁在听,得有人记着 | 举手报名进某色组,墙上一本组名册 |
| IP分组 + 组播地址 + IGMP + 分组转发 | **IP组播** | 一次发送、组内都收;D类224/4映射到组播MAC,IGMP维护成员,沿组播树按成员复制转发 | 网络层三种交付里补上一对一组 | 一次投递沿组播树分叉送到每个订户 |
| 进程 + 权威 | **控制器** | 一个被赋予全网转发决定权的逻辑集中进程,统一算路再下发 | 把转发决策从每台设备抽到一处 | 中央大脑塔台俯瞰全网 |
| 映射 + 约定码 | **流表** | 一张多字段匹配→动作的表(匹配上就取约定动作码执行),比只看目的IP通用 | 转发不再只按目的IP,任意字段皆可匹配 | 一本看到这种包就这么处理的动作对照册 |
| 分组转发 + 控制器 + 流表 | **SDN** | 把控制平面从每台设备抽到逻辑集中控制器,用流表做多字段匹配+动作的通用转发 | 转发与控制彻底分离:数据面退化成只照流表执行,全网策略集中在控制器一处改 | 控制器下发流表,交换机只照表执行 |
| IP地址 + IP首部 + ICMP + 可软配置 | **IPv6** | 地址扩到128位、简化首部去校验和、取消途中分片(源端按PMTU切)、内建自动配置(可软配置到无状态) | 近乎无限地址→端到端可达性回归,不再需要NAT | 门牌从4段升成8段冒号缩写的超长灯牌 |
| 接口 + 路由表 + 分组转发 + 最长前缀匹配 + OSPF + BGP + ICMP + 默认网关 + RIP | **路由器** | 把全部组件装进有N个接口、标称转发吞吐的盒子;能跨哪些网、口数速率由塞进的组件决定 | 一台把多张异构网缝在一起、自主为每个分组选路的唯一规格实物:N口×每口速率×支持哪些路由协议 | 暖黄机箱,一排接口灯+翻牌分拣板+RIP/OSPF/BGP徽章+红哨,招牌规格千兆8口 |

| 名字 + 映射 + 约定码 + 有效期 | **资源记录** | 名字→值登记,类型码定值:A/AAAA=IP、MX=邮局、CNAME=别名、NS=下级权威,带TTL | 把人类名字挂接到机器目标,绑定可缓存有保质期 | 档案卡四栏:名字/类型印章/值/沙漏 |
| 域名 + 资源记录 + 映射 + 中间人 | **DNS解析** | 名字交本地解析器,替你从根→顶级→权威顺委派链问下来,拿A记录回给你并按TTL缓存 | 人只念名字就拿到IP,多数查询就近命中缓存 | 接线员拿名字树顺蜡封章一站站打电话,末了递门牌灯 |
| 域名 + 资源记录 + 中间人 | **DNS迭代递归查询** | stub→本地解析器多为递归(你替我问到底),本地→各级权威多为迭代(我只答下一步找谁) | 把"一路问到底"的累活从客户端卸给递归解析器,权威服务器因此能无状态地各只答一步 | 一个包问到底的跑腿,一路上各权威只指下一家找谁 |
| IP地址 + 子网掩码 + 默认网关 + 有效期 + 客户端-服务器 | **DHCP** | 开机DORA(Discover/Offer/Request/Ack)广播租用IP/掩码/网关/DNS+租期;因IP天生软分配才能这样发 | 即插即用入网;地址从固定资产变成可回收公共资源 | 物业发号窗口,递带到期日的整套上网参数 |
| 副本 + 有效期 + 元数据 + 中间人 | **Web缓存** | 留一份副本,TTL内直接给,过期带指纹做条件请求问变了没,没变续期 | 就近命中更快省带宽,源站用缓存指令精确控制 | 驿站小二货架码着贴沙漏的副本,顾客再来先翻货架 |
| Web缓存 + 中间人 + 副本 + DNS解析 | **CDN** | 把副本铺到全球边缘缓存,用DNS按用户位置解析到最近边缘节点取货 | 全球就近+抗高并发,一个远源变无数近副本 | 世界地图上星罗棋布的小驿站各存一份 |
| 状态 + 元数据 + 名字 | **Cookie** | HTTP无状态,服务器把记忆写成Set-Cookie小纸条交客户端保管,每次原样带回 | 无状态HTTP上凭空长出会话/登录态 | 寄存木牌,进门亮一下老板就想起你 |
| Cookie + 状态 + 映射 | **会话** | 客户端只带不透明会话ID,真状态存服务器,用ID映射到服务器侧那本记事本 | 把互不相识的请求串成同一个人的连续交互 | 柜台后一排记事本,号码对得上那本是你的 |
| URL + 资源 | **超链接** | 在一份资源里嵌指向另一份的URL,点一下就对目标发起请求跳过去 | 资源互指连成可跳转的网——万维网的网 | 发光丝线,一端缝这页一端拴远处包裹 |
| 资源 + 元数据 + 超链接 | **HTML超文本** | 成对标签把内容标注结构/语义,浏览器照标记渲染;标记是元数据 | 机器解析结构、人看排版、内嵌跳转与资源 | 乐高说明书,文字外套彩色标签框 |
| URL + HTML超文本 + 超链接 + HTTP报文 + 客户端-服务器 | **WWW万维网** | 统一命名(URL)+统一传输(HTTP)+可互链超文本(HTML)三件套织成全球网 | 一张网:任意资源可命名、取回、互链跳转,靠点击漫游 | 暖色毛线球星球,表面爬满发光丝线 |
| 内容/数据 + 编码/表示 | **序列化字节** | 同一份内容按ASCII/UTF-8/Base64序列化成可传字节;MIME、字符集协商建其上 | 任意异构系统只要共享同一套编码,就能无歧义地还原出同一份内容——互操作性 | 打字机把内容敲成一排标准符号 |
| 密钥 + 报文 | **对称加密** | 收发共享同一把密钥,发前搅成噪声,收后同钥还原 | 机密性:中间人看得见字节读不懂内容 | 暗箱,信塞进咔哒上锁变花纹 |
| 哈希 + 报文 | **数字摘要** | 内容过哈希得指纹一起发,收方重算比对;对不上=路上出了差错。挡得住意外损坏,但挡不住蓄意篡改——攻击者改完顺手重算指纹 | 完整性:能查出意外损坏/传输差错(防篡改要等下游HMAC带上密钥) | 蜡封指纹盖封口,谁动过就对不上 |
| 哈希 + 密钥 | **消息认证码HMAC** | 纯哈希挡不住主动攻击者(改内容顺手重算指纹),需带密钥的哈希 | 完整性+真实性;TLS记录层实际用它而非裸哈希 | 蜡封机里先掺一把只有双方知道的密钥再压指纹,没那把钥匙就伪造不出 |
| 哈希 + 非对称密钥对 | **数字签名** | 私钥给指纹加封,任何人用配对公钥验封;私钥不外泄故只有本人能产生 | 来源认证+不可抵赖(比纯摘要多出是谁) | 私章蘸只有主人有的印泥,别人只能验盖不出 |

| 数字证书 + 权威 + 数字签名 | **信任链** | 叶证书由中级CA签、中级由根签,根CA预装被无条件信任,逐级上溯到根 | 有限几个根信任撑起全网可信 | 一串套娃图章,最外层根章早钉在你怀里 |
| 非对称密钥对 + 密钥 | **密钥交换** | 双方在公开信道各自算出同一共享秘密、谁都没把它发出去(前向保密),≠用公钥加密传密钥 | 握手的心脏,前向保密基础 | 两人各调一半颜料,当众混合却算不出对方那半 |
| 数字证书 + 信任链 + 非对称密钥对 + 对称加密 + 消息认证码HMAC + 密钥交换 + 发起 + 约定码 | **TLS安全信道** | 握手用证书+非对称验身份并DH协商临时对称密钥,此后每条报文对称加密(保密)+HMAC(防改);HTTPS=HTTP跑在里面 | 公开不可信网络上同时得机密+完整+身份认证的三合一私密管道 | 暖色安全气管:入口验身份证,管壁不透明,每节带蜡封 |
| 报文 + 名字 + 资源 | **电子邮件与信箱** | 带信封头(发/收/主题)的报文;user@domain左=信箱名右=域名(靠MX找邮局) | 异步留言:对方不在线也能先替他收着 | 带地址窗口的信封,右上贴邮票 |

## 四、几件唯一实物(合成树顶)

> 共 57 个树顶(含各支终点知识点)。下面挑几件"有真实规格的实物",列直接配方 + 它的唯一规格(=涌现)。

**【路由器】** ← 接口 + 路由表 + 分组转发 + 最长前缀匹配 + OSPF + BGP + ICMP + 默认网关 + RIP  
　规则:把全部组件装进有N个接口、标称转发吞吐的盒子;能跨哪些网、口数速率由塞进的组件决定  
　唯一规格(涌现):一台把多张异构网缝在一起、自主为每个分组选路的唯一规格实物:N口×每口速率×支持哪些路由协议

**【服务器】** ← 接口 + 套接字 + 复用分用 + TCP连接 + 可靠传输 + 流量控制 + 拥塞控制 + HTTP报文 + TLS安全信道  
　规则:把这些网络组件装进一台主机;能扛多少并发由套接字+复用分用+TCP四元组决定,吞吐由接口速率决定,是否HTTPS由HTTP报文+TLS决定  
　唯一规格(涌现):一台唯一规格网络实物,招牌只认网络派生规格:N万并发连接 / X Gbps吞吐 / 支持HTTPS

**【CDN】** ← Web缓存 + 中间人 + 副本 + DNS解析  
　规则:把副本铺到全球边缘缓存,用DNS按用户位置解析到最近边缘节点取货  
　唯一规格(涌现):全球就近+抗高并发,一个远源变无数近副本

**【局域网】** ← 以太网 + 交换机 + 广播域 + ARP  
　规则:同广播域内靠MAC+ARP直接可达不需路由器;一个IP子网通常正好映射一个LAN  
　唯一规格(涌现):内部人人可直达、对外统一走网关的本地网

**【VLAN】** ← 交换机 + 帧 + 标识 + 广播域  
　规则:给口/帧打12位VID,只有同VLAN才互转互广播,跨VLAN必须上三层  
　唯一规格(涌现):不重新布线就把广播域逻辑切开、按部门隔离

**【WWW万维网】** ← URL + HTML超文本 + 超链接 + HTTP报文 + 客户端-服务器  
　规则:统一命名(URL)+统一传输(HTTP)+可互链超文本(HTML)三件套织成全球网  
　唯一规格(涌现):一张网:任意资源可命名、取回、互链跳转,靠点击漫游
