# 虾米世界 · 方案（2026-08-22 定稿）

> 这份文档取代之前所有"小镇 / 维修工"路线的设计。旧的看 `docs/archive/`。

## 一句话

**你家的一套三室两厅。屋里每样天天在用的东西，坏了、慢了、不对劲了，
背后都藏着一个真实可运行的仿真实验。AI 助手「咕噜」陪你搞懂它。**

不是在游戏里教知识，是**让知识成为这套房子运行的规则**。

## 它是什么、不是什么

**是**：知识解密、寓教于乐。玩家离开时留下的是「**我搞懂了一件事**」。
**不是**：套了知识皮的游戏。分数越诱人越没人学 —— 所以**竞技分数榜不做，排行榜只排"懂"**。

---

## 一、壳：一套房子（不是小镇）

为什么是房子：

1. **代入感自带** —— 是"我家"，不是"别人的委托"。动机不用编：东西是你的。
2. **容量大一个量级** —— 一间厨房就是冰箱+燃气灶+油烟机+微波炉+电磁炉；
   而且**软装硬装本身也能拆**（墙返潮=露点、承重墙=力学、下水道味=存水弯、朝南更暖=日照得热）。
3. **天然分发** —— 每样东西观众自己家也有。「原来我家冰箱是这样」比虚构小镇的水车强太多。

**房间即解锁单元**，一件设备一个副本，一个副本不止一个知识点。

## 二、核：知识解密

### 通关两层
| 层 | 要求 | 防的是 |
|---|---|---|
| **做到**（手） | 把它修好 / 配好 | 空谈 |
| **说清**（脑） | 答上只有真懂才答得上的问题 | 瞎撞蒙对 |

两个都过，才算真懂。

### 判定与姿态（定稿原话）
> **判定严格，姿态温柔，不给答案只换角度，答错就邀请你回去做实验，而且它记得你卡在哪。竞争交给榜，不交给惩罚。**

- 答不上来 = 没过（判定不松）
- 但不罚站、不踢出去：**换个问法、给个类比、拆小一步**，那句结论必须**你自己说出来**
- 答错 → **邀请你回去做一次针对性实验**（"你说加厚保温电费会涨？来，只改保温跑一次看看"）
- **咕噜记得你哪儿卡过**，下个副本遇到同一个原理会回头点你

### 招牌机制：先押后验
**动手前先押"会往哪走" → 求解器真跑 → 先让结果打脸 → 咕噜再进来解释。**

- **主力 = 押方向/趋势**（"多还是少"人人答得上）；**押准确数值 = 高手模式**
  → 门槛低、天花板高，同一个机制一条连续坡道
- **可跳过，但跳过不计榜**
- **押错方向 = 金矿**：说明心智模型是反的，这是最该讲的一刻
- **必须先给锚点**（"现在 21℃、环境 32℃"），没锚点的押注是抽奖不是理解

**防刷四条**（答案会被记住这个洞的解法）：
1. **参数每次随机** —— 记住数字没用，只能靠算
2. **押关系/趋势**（边际递减、谁影响更大）—— 能被记住的恰好正是该教的
3. **押迁移**（换个环境还成立吗）—— 最防刷，也最接近真懂
4. **重玩不计榜** —— 不禁止练习，考场和练习场分开

> **凡能被求解器算出来的，就能随机出题；凡能随机出题的，就刷不了。**
> 题库不用人工写。

### 排行榜：排"懂"不排"分"
| 榜 | 为什么防刷 |
|---|---|
| 一次通过率（试几次才对） | 瞎试的人次数天生就多 |
| **预测准确度** | **不懂就押不准（最硬）** |
| 关底问答成绩 | 刷分的唯一办法是真懂 |

- 效率榜（最省电/最快）**降级**：必须先通过关底问答才解锁 —— **先懂，再卷**
- 总榜看**预测准确率随时间的曲线** = 学习轨迹，同时满足"跟自己比"+"跟所有人比"
- 后端只存参数（求解器重放，不存录像）
- **几维取舍就几个榜，绝不合成总分** —— 合了就杀死多解

### 题型两类（不是所有知识都能多解）
- **资源/设计型**（制冷、功率预算、Cache 配置、推理批处理）→ 约束设计题、帕累托前沿、可押可优化
- **诊断/算法型**（找断点、KMP）→ 天生单解，当"啊哈小品"调节奏

同一物件**两吃**：先「修坏的那台」（诊断，新手）→ 再「配一台更好的」（设计，发烧友）。

---

## 三、AI 助手「咕噜」

**诊断题里**：导航到唯一答案。
**优化题里**：**讲因果 + 点破取舍 + 从不替你拍板**（一给答案就把开放解压成单解）。
**关底**：当考官，判断你是不是真懂了 —— 这是模型最不可替代、也最该收钱的位置。

**铁律（比诊断题里更严）**：可以不给答案，但**讲的每条因果必须是求解器真算的**。
在优化题里瞎解说，玩家会照它优化然后被真实结果打脸 —— 那是最坏的体验。

**AI 只在认知节点出现，不进 60fps 机械回路。**

> 这一条也是跟佐藤（Opus Magnum）的分界：佐藤默认你已经懂 → 受众窄；
> 有咕噜带 → 面向所有人。

## 四、主菜：书房那台电脑

桌上电脑挂**感叹号**吸引点击。点进去先看到**症状**（不是关卡菜单）：网页转圈 / 游戏掉帧 / AI 转圈。
**一台机器长出三个系列**，深度递进、受众扩大：

```
书房那台电脑
├── A · 网络       路由器 / WiFi / DNS / VPN / 带宽      门槛最低，人人有共鸣
├── B · 机器内部   CPU / 内存 / 闪存 / GPU / 磁盘        主力，408 组成原理+OS
└── C · 自部署大模型  显存 / KV Cache / 批处理 / 量化 / 多卡   最深、最值钱
```

**C 跟 B 同源**，这是最值钱的一次押韵：

| B（家用电脑） | C（AI 机器） | 复用 cs-lab |
|---|---|---|
| 内存爆了、换页抖动 | 显存装不下、KV Cache 吃显存 | `page.ts` |
| Cache 命中率 | 前缀缓存、KV 驱逐 | `cache.ts` |
| 流水线 | 多卡张量/流水线并行 | `pipeline.ts` |
| 进程调度 | 连续批处理排队 | `scheduler.ts` |

玩家在 B 建立的直觉，到 C 原样能用。**求解器不从零写 —— 把 cs-lab 验证过的内核换个坐标轴。**

### 「押方向」题样例（都极反直觉）
- **A**：换 500M 宽带会变快吗？→ 多数情况几乎没变（瓶颈在 WiFi/延迟）
- **A**：网页打不开但游戏能玩 → DNS
- **B**：换更强 CPU 会变快吗？→ 几乎没变（内存墙）
- **B**：加内存能快多少？→ **非线性台阶**（不爆没用，爆了天差地别）
- **B**：风扇开大反而更快 → 解除降频，代价是吵
- **C**：显存 24G 够跑吗？→ 权重装得下 ≠ 能用，KV Cache 才是大头
- **C**：并发 1→10，吞吐涨 10 倍吗？→ 吞吐涨了但每个人延迟也涨（没有免费的午餐）

**顺序**：先诊断（修一台卡的），后设计（给这台配一套升级，预算多少怎么花最值）。

## 五、表现

| 层 | 风格 | 为什么 |
|---|---|---|
| 世界层（房子/房间） | **剖面暖色插画** | 要"像家"，温暖、有代入感 |
| 实验层（钻进设备内部） | **工程蓝图冷线框** | 要"能读懂"，精密、可诊断 |

叙事：**解锁线性**（房间/设备一件件开）+ **单副本内解法开放**（佐藤结构）。

参照：**Opus Magnum / Shenzhen I/O 是最该研究的先例**（硬核理论做成解谜、开放解、
多维直方图不合总分）。塞尔达究极手 = 知识必须是可操作的世界规则。双人成行 = 偷哲学不偷体量。
