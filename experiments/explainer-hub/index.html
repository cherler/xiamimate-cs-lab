本地 · 真模型

浏览器端真推理原型

纯浏览器跑 Qwen2.5（transformers.js + WebGPU），没有服务器。

  • 真实的中文分词 —— 一个汉字≈一个 token，不会碎成星号
  • 下一个词的 top-k 概率 + 续写
  • 可切 0.5B / 1.5B，精度可选 q4f16 / q4 / q8
  • 首次载入要下模型权重（0.5B 约 460MB，之后缓存在浏览器里）

开源 · poloclub（MIT）

Transformer Explainer

Georgia Tech Polo Club 做的那份经典可视化：把 GPT-2 的一次前向整个画出来。

  • 嵌入 → QKV → 注意力热力图 → MLP → 输出概率，逐块可点
  • 可以拖温度、看每一层每个头在看哪儿
  • 模型是 GPT-2：英文为主，中文会碎成星号（这正是左边那份存在的理由）
打开官方在线版 ↗
想在本机跑一份？代价要先知道：GPT-2 权重是 static/model-v2/ 下 626MB 的 ONNX 分片，路径写死在代码里、没有远程开关；另外要装 SvelteKit 依赖并 build。 所以先接官方在线版。

社区 fork · 中文 Qwen3（MIT）

中文增强版（Qwen3-0.6B）

把上面那份整个汉化，并把模型从 GPT-2 换成 Qwen3-0.6B（也可跑 4B）。

  • 中文不碎 —— 151,936 双语词表，敲"天生我材必有用，"能正常看下一个词
  • 架构也换新了：GQA（16Q×8KV）+ SwiGLU + RoPE，对齐现代 LLM 主流
  • WebGPU 本地推理，1.44GB fp16 模型直接在浏览器里跑
  • 仓库本身只有 9.6MB（不含权重），脚本自动从 HF 镜像 / ModelScope 拉
看仓库 ↗
它没有在线 demo，只能本机跑，门槛也实在：Node ≥20 + Python ≥3.10（torch/transformers/onnx）、 16GB 内存、支持 WebGPU 的 Chrome/Edge、约 4GB 硬盘，首次搭建 10–20 分钟。 要不要把它接进 /lab/，说一声我来弄。
